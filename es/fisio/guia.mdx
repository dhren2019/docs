FISIO permite revisar la colocación de un tatuaje sobre un **modelo corporal 3D genérico**. Ayuda a explorar forma, orientación y continuidad visual, pero no reproduce el cuerpo real de un cliente.

<Steps>
  <Step title="Selecciona una sesión con colocación">
    Abre **FISIO** y elige una sesión. Si aparece **Sin modelo 3D guardado** o **Falta colocar el diseño**, abre la sesión, completa la colocación y guárdala.
  </Step>
  <Step title="Examina el diseño">
    En la vista central puedes utilizar los controles de cámara para rotar, acercar, alejar, encuadrar el modelo o ir al tatuaje.
  </Step>
  <Step title="Revisa las transformaciones">
    En **Colocación** consulta o ajusta **Escala**, **Rotación** y **Posición**. También puedes seleccionar los modos **Estándar**, **Conformar** o **Envolver**.
  </Step>
  <Step title="Guarda la colocación">
    Si has modificado la transformación, pulsa **Guardar colocación** antes de registrar el criterio de las observaciones.
  </Step>
  <Step title="Explora las guías">
    Activa o desactiva las referencias visuales de **Eje**, **Curva**, **Giro**, **Lectura**, **Puntos clave** y **Zona de movimiento** para entender la disposición sobre el modelo.
  </Step>
</Steps>

## Cómo leer las guías

| Guía | Para qué sirve |
| --- | --- |
| Eje | Dirección longitudinal de la zona representada |
| Curva | Recorrido transversal sobre la colocación |
| Giro | Orientación angular del diseño |
| Lectura | Línea central de referencia |
| Puntos clave | Referencias de extensión sobre la superficie |
| Zona de movimiento | Franjas predefinidas de flexión |

<Warning>Simulación sobre modelo genérico. No representa el cuerpo exacto del cliente y no mide anatomía ni riesgos clínicos individuales.</Warning>
