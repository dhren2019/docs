FISIO helps you examine the placement of a tattoo design on a **generic 3D body model**. It provides visual geometry references rather than a personalised scan or a clinical assessment.

<Steps>
  <Step title="Choose a prepared session">
    Open FISIO and select a session. If you see **Sin modelo 3D guardado** or **Falta colocar el diseño**, return to the session and save the model and placement first.
  </Step>
  <Step title="Inspect the 3D viewer">
    Use camera controls to rotate, zoom, frame the model, or focus on the tattoo.
  </Step>
  <Step title="Adjust the placement">
    Review **Escala** (scale), **Rotación** (rotation), and **Posición** (position). Projection options are **Estándar**, **Conformar**, and **Envolver**.
  </Step>
  <Step title="Save changes">
    When you modify the transform, select **Guardar colocación** before making decisions on the resulting observations.
  </Step>
  <Step title="Toggle the visual guides">
    Enable or disable **Eje** (axis), **Curva** (curve), **Giro** (rotation), **Lectura** (reading), **Puntos clave** (key points), and **Zona de movimiento** (movement area).
  </Step>
</Steps>

| Guide | Purpose |
| --- | --- |
| Axis | Longitudinal direction along the reference region |
| Curve | Cross-sectional trajectory on the placement |
| Rotation | Orientation arc of the saved design |
| Reading | Central reference line |
| Key points | Extent references on the model surface |
| Movement area | Predefined reference areas of flexion |

<Warning>The generic model does not represent the client's exact body. FISIO does not measure patient-specific anatomy or clinical risk.</Warning>
